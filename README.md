# Bin Rabie Holding Group | مجموعة بن ربعي القابضة

Corporate website for **Bin Rabie Holding Group**, a Saudi holding company operating across 7 sectors with 11 subsidiaries and 500+ employees.

![Hero](screenshot.png)

## Features

- Bilingual support (Arabic / English)
- Cinematic loader with animated intro
- Interactive org chart for leadership team
- Company cards with category filtering
- Responsive design for all devices
- Contact form integration

![About Section](screenshot2.png)

![Companies Section](screenshot3.png)

## Tech Stack

- HTML5 / CSS3 / JavaScript
- Custom AOS (Animate On Scroll) system
- Glassmorphism UI design
- CSS Grid & Flexbox layouts
